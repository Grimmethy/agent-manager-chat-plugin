# Phase 4 exit checklist: a week of real use

This is for the **owner** to fill in. Nothing below is ticked, and nothing in this repo claims it has been done.

The exit check from the design plan, as it was handed to the multi-chat work: **use the in-app chat for a week with no fallback to a raw Claude Code terminal for monitoring.** Monitoring means watching what the sessions are doing and noticing when one needs you.

## Before the week

- [ ] The polish features in `README.md` ("Multi-chat polish") are on the page you will use.
- [ ] You have gone through `VERIFY.md` at least once and noted anything that did not work.
- [ ] Chat panes, the session switcher and (if used) the session agent are running on the machines you watch.
